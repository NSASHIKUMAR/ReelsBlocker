# ReelsBlocker
No More DoomScrolling

A small personal Android app for your Samsung S25. It watches Instagram and YouTube, and the moment you land on the Reels viewer or the YouTube Shorts player, it presses Back for you. Stories, feed, photos and messages keep working. It has no internet permission, so it cannot send anything anywhere. The detection idea is adapted from the MIT-licensed Reel Block project by SuzalShrestha.
